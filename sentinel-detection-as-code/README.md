# Sentinel Detection as Code

Repository scaffold for Microsoft Sentinel detection content.

## Structure

- `detections/azure/` - Azure detection content
- `detections/identity/` - Identity detection content
- `detections/endpoint/` - Endpoint detection content
- `detections/network/` - Network detection content
- `tests/` - Detection validation and test assets
- `docs/` - Project documentation
- `.github/workflows/` - GitHub Actions workflows

The detection directories are organized by data source or domain. Add detection
rules and their corresponding tests as the project grows.
